# 🚗 DrivePass+ 

**Неограниченная чистота. Неограниченная езда.**

Премиум приложение для подписки на автомойку за $25/месяц с неограниченными ежедневными мойками в партнерских локациях.

---

## 🎉 Что нового - ВСЕ ФУНКЦИИ РЕАЛИЗОВАНЫ!

### ✨ Progressive Web App (PWA)
- 📲 Устанавливается на телефон как нативное приложение
- 🚀 Работает офлайн с кешированными данными
- 🔔 Поддержка push-уведомлений
- 📱 Идеальный опыт на iOS и Android

### 🔐 Полная Backend Интеграция
- ✅ Аутентификация пользователей (регистрация/вход)
- ✅ История моек синхронизирована с облаком
- ✅ Реальные данные с Supabase
- ✅ Защищенные API эндпоинты

### ⭐ Отзывы и Рейтинги
- Пишите отзывы о локациях
- Система рейтинга 5 звезд
- Значок проверенной мойки
- Сортировка по новизне или полезности

### 🎁 Программа Лояльности
- Зарабатывайте 10 баллов за мойку
- 4 уровня членства (Бронза → Платина)
- Обменивайте баллы на награды
- Отслеживайте свой прогресс

## 📱 Быстрый Старт

### Для Пользователей:

1. **Откройте в мобильном браузере** (Safari на iOS, Chrome на Android)
2. **Добавьте на главный экран**:
   - iOS: Нажмите Поделиться → "На экран Домой"
   - Android: Нажмите Меню → "Добавить на главный экран"
3. **Запустите приложение** с главного экрана
4. **Зарегистрируйтесь** с email и паролем
5. **Начните мыть!** Сканируйте QR-коды в партнерских локациях
