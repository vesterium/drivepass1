## 🎓 МАРКЕТИНГОВЫЙ ПЛАН

### 1. Instagram (Основной канал)

**Контент:**
- До/После фото машин
- Видео процесса мойки
- Отзывы клиентов
- Stories: "Моем 8 раз в месяц"
- Reels: "Как работает DrivePass"

**Таргетинг:**
- Возраст: 25-45
- Город: Самарканд
- Интересы: Автомобили, бизнес
- Доход: средний+

### 2. Партнерская программа

**Для мойщиков:**
```
Зарегистрируй клиента →
Получи 5,000 сум наличкой!

Клиент получает скидку 10,000 сум
```

**Механика:**
1. Мойщик показывает QR клиенту
2. Клиент регистрируется
3. В промокоде вводит код мойщика
4. Мойщик получает бонус

### 3. Сарафанное радио

**Триггеры:**
- Клиент моет машину → видят другие
- Клиент хвастается подпиской
- Клиент экономит деньги

**Механизм:**
```
"Друг, где моешь?"
"На автомойке Х по подписке!"
"Сколько?"
"220,000 в месяц, 8 раз мою!"
"Дай ссылку!"
```

## 📞 SUPPORT

### Если что-то сломается:

**Откройте консоль браузера (F12):**
```
Проверьте логи:
- Есть ли ошибки (красный текст)?
- Какие запросы падают?
- Что пишет в console.log?
```

**Частые проблемы:**

| Проблема | Решение |
|----------|---------|
| "Can't connect to Supabase" | Проверь интернет |
| "Invalid credentials" | Проверь email/password |
| "No session found" | Очисти localStorage → попробуй снова |
| PWA не устанавливается | Нужен HTTPS (deploy на Vercel) |
| QR не сканируется | Увеличь яркость экрана |
