## 🎯 ЧТО ЭТО

**DrivePass+** - это **агрегатор автомоек с подписочной моделью** для рынка Узбекистана.

### Простыми словами:
```
Ты платишь фиксированную сумму в месяц
         ↓
Моешь машину НЕОГРАНИЧЕННО
         ↓
На ЛЮБОЙ партнерской мойке
         ↓
Просто показываешь QR код
```

### Аналоги в мире:
- **Wash Club** (США) - subscription car wash
- **Unlimited Wash Club** (Великобритания)
- **Fitness-модель** - как абонемент в спортзал, но для автомоек

### Технически:
```
Progressive Web App (PWA)
    +
QR-код система оплаты
    +
Geolocation для поиска моек
    +
Real-time база данных
    +
24-часовой anti-abuse механизм
```

## 💡 СУТЬ И КОНЦЕПЦИЯ

### Слоган:
> **"Smart Car Care. Экономь каждый день"**

### Главная идея:
**Превратить хаотичный рынок автомоек в единую экосистему с предсказуемыми расходами**

### Как это работает:

#### ДЛЯ КЛИЕНТА:
```
1. Скачиваешь PWA приложение
   ↓
2. Регистрируешься по телефону (+998)
   ↓
3. Указываешь госномер машины
   ↓
4. Покупаешь подписку (Personal или Business)
   ↓
5. Приезжаешь на ЛЮБУЮ партнерскую мойку
   ↓
6. Показываешь QR код из приложения
   ↓
7. Мойщик сканирует → мойка бесплатна
   ↓
8. Следующая мойка доступна через 24 часа
```

#### ДЛЯ ВЛАДЕЛЬЦА АВТОМОЙКИ:
```
1. Регистрируется как партнер
   ↓
2. Получает Washer Panel (панель мойщика)
   ↓
3. Мойщик сканирует QR клиента
   ↓
4. Система проверяет:
   - Активна ли подписка?
   - Прошло ли 24 часа с последней мойки?
   - Совпадает ли госномер?
   ↓
5. Если OK → зеленый экран ✅
6. Если НЕТ → красный экран ❌
   ↓
7. В конце месяца: выплата от DrivePass+
   (фиксированная сумма за каждую мойку)
```

### Почему это работает:

**Психология клиента:**
- "Я уже заплатил → надо отбить деньги" → моет чаще
- Нет стресса "сколько стоит" при каждой мойке
- Чувство премиальности (как VIP карта)

**Экономика бизнеса:**
- Клиент платит 220,000 сум/месяц
- Средняя мойка стоит 30,000 сум
- Если клиент моет 7+ раз → убыток
- НО: Большинство моет 4-6 раз → прибыль
- Лимит 24 часа защищает от extreme users

## 👥 ЦЕЛЕВАЯ АУДИТОРИЯ

### Сегмент 1: Personal (220,000 сум/мес)

**Портрет клиента:**
```
Возраст:        25-45 лет
Пол:            70% мужчины, 30% женщины
Доход:          $500-2000/мес
Автомобиль:     Средний класс (Cobalt, Gentra, Nexia)
Город:          Ташкент, Самарканд, Бухара, Андижан
Работа:         Офисные сотрудники, менеджеры, малый бизнес
```

**Боли:**
- Машина грязная, но лень искать мойку
- Каждый раз надо думать "а стоит ли тратить 30к?"
- Разные цены на разных мойках → неопределенность
- Нет времени стоять в очереди на популярных мойках

**Мотивация:**
- Хочет всегда чистую машину БЕЗ стресса
- Любит предсказуемые расходы
- Ценит удобство (QR код быстрее налички)
- Хочет почувствовать себя VIP

**Частота мойки:**
- Летом: 6-8 раз в месяц (пыль)
- Зимой: 4-5 раз в месяц (грязь)
- **Средняя: 5 раз** → окупается если мойка >44,000

### Сегмент 2: Business для такси (450,000 сум/мес)

**Портрет клиента:**
```
Возраст:        25-55 лет
Пол:            95% мужчины
Доход:          $300-1000/мес (от такси)
Автомобиль:     Рабочая лошадка (Cobalt, Damas, Nexia)
Работа:         Таксисты (Yandex, MyTaxi, InDriver)
```

**Боли:**
- Машина грязная → меньше заказов (пассажиры выбирают чистые)
- Нужно мыть КАЖДЫЙ ДЕНЬ или через день
- Тратит 300-400к/месяц на мойки → ОГРОМНЫЕ расходы
- Теряет время на мойках вместо работы

**Мотивация:**
- ДЕНЬГИ! Чистая машина = больше рейтинг = больше заказов
- Экономия: 450к подписка VS 300-400к наличными
- Время: QR код быстрее чем платить каждый раз
- Сеть моек: не надо искать "свою" мойку

**Частота мойки:**
- Лето: 15-20 раз в месяц
- Зима: 10-15 раз в месяц
- **Средняя: 15 раз** → окупается ВСЕГДА (15×30k = 450k)

### Сегмент 3: Корпоративный (будущее)

**Потенциал:**
- Компании с автопарком (10+ машин)

**Возможности PWA:**
```
✅ Установка на главный экран (как нативное приложение)
✅ Работает офлайн (показывает кэш)
✅ Push-уведомления ("Пора помыть машину!")
✅ Быстрая загрузка (кэш ресурсов)
✅ Не занимает место (в отличие от нативного)
✅ Обновления автоматические (без App Store)
```

**Почему PWA а не нативное приложение?**

| Критерий | PWA | Native App |
|----------|-----|------------|
| Разработка | 1 кодовая база | 2 базы (iOS + Android) |
| Время | 2-3 месяца | 6-8 месяцев |
| Стоимость | $5,000 - 10,000 | $30,000 - 50,000 |
| Обновления | Мгновенно | Ревью App Store (7 дней) |

### Key SQL Functions

```sql
-- Проверка: может ли пользователь мыть машину сейчас?
CREATE OR REPLACE FUNCTION can_wash_now(p_user_id UUID)
RETURNS BOOLEAN AS $$
DECLARE
  last_wash_next_available TIMESTAMP;
BEGIN
  -- Получаем время когда доступна следующая мойка
  SELECT next_available_wash INTO last_wash_next_available
  FROM wash_history
  WHERE user_id = p_user_id
  ORDER BY washed_at DESC
  LIMIT 1;
  
  -- Если моек не было → можно мыть
  IF last_wash_next_available IS NULL THEN
    RETURN TRUE;
  END IF;
  
  -- Если прошло 24 часа → можно мыть
  IF NOW() >= last_wash_next_available THEN
    RETURN TRUE;
  END IF;
  
  -- Иначе → нельзя мыть
  RETURN FALSE;
END;
$$ LANGUAGE plpgsql;

-- Получить оставшееся время до следующей мойки
CREATE OR REPLACE FUNCTION time_until_next_wash(p_user_id UUID)
RETURNS INTERVAL AS $$
DECLARE
  last_wash_next_available TIMESTAMP;
BEGIN
  SELECT next_available_wash INTO last_wash_next_available
  FROM wash_history
  WHERE user_id = p_user_id
  ORDER BY washed_at DESC
  LIMIT 1;
  
  IF last_wash_next_available IS NULL THEN
    RETURN INTERVAL '0 seconds';
  END IF;
  
  IF NOW() >= last_wash_next_available THEN
    RETURN INTERVAL '0 seconds';
  END IF;
  
  RETURN last_wash_next_available - NOW();
END;
$$ LANGUAGE plpgsql;
```

### Row Level Security (RLS) Policies

```sql
-- Пользователи видят только свои данные
ALTER TABLE users ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can read own data"
ON users FOR SELECT
USING (auth.uid() = id);

CREATE POLICY "Users can update own data"
ON users FOR UPDATE
USING (auth.uid() = id);

-- История моек: только свои
ALTER TABLE wash_history ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can read own wash history"
ON wash_history FOR SELECT
USING (auth.uid() = user_id);

-- Мойщики видят только мойки своей автомойки
ALTER TABLE wash_history ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Washers can read washes at their car wash"
ON wash_history FOR SELECT
USING (
  EXISTS (
    SELECT 1 FROM washers
    WHERE washers.user_id = auth.uid()
    AND washers.car_wash_id = wash_history.car_wash_id
  )
);

-- Все видят автомойки (публичная информация)
CREATE POLICY "Anyone can read car washes"
ON car_washes FOR SELECT
TO authenticated
USING (true);
```

## 🏆 КОНКУРЕНТНЫЕ ПРЕИМУЩЕСТВА

### Почему DrivePass+ выиграет на рынке:

#### 1. First Mover Advantage
```
В Узбекистане НЕТ конкурентов!
- Carwash.uz - только справочник (нет подписок)
- Mybozor.uz - объявления (нет системы)
- Отдельные мойки - своя система (несовместимо)

DrivePass+ = ПЕРВЫЙ агрегатор с подпиской
```

#### 2. Защита от убытков (24ч лимит)
```
Конкуренты в США потеряли миллионы:
- Unlimited Wash Club закрылся (abuse)
- Wash Club добавил лимит 1 мойка/день ПОЗЖЕ

Мы учли эту ошибку С САМОГО НАЧАЛА:
- 24 часа = оптимальный баланс
- Клиент доволен (может мыть часто)
- Бизнес защищён (не более 30 моек/мес)
```

#### 3. Unit Economics работает
```
Personal клиент:
LTV/CAC = 22.8 (отлично!)
Payback = 0.5 месяца

Business клиент:
LTV/CAC = 11.25 (хорошо!)
Payback = 1 месяц

Конкуренты часто:
LTV/CAC < 3 (плохо)
Payback > 6 месяцев
```

#### 4. PWA вместо нативного
```
Экономия:
Разработка: -$20,000
Поддержка: -$1,000/мес
Time to market: -4 месяца

НО те же фишки:
✅ Установка на главный экран
✅ Push-уведомления
✅ Офлайн режим
✅ Быстро работает
```

#### 5. Локализация (3 языка)
```
Конкуренты: только русский
Мы: EN + RU + UZ

Узбекский язык = доверие у местных
Английский = экспаты, туристы
```

#### 6. Trust Indicators (индикаторы доверия)
```
❌ Конкуренты:
- Нет отзывов
- Нет рейтингов
- Нет истории
- Нет гарантий

✅ Мы:
- Рейтинг моек (как Yandex Taxi)
- История всех моек
- Возврат денег если недоволен
- Страхование (на будущее)
- Чат поддержки 24/7
```

#### 7. Network Effect (сетевой эффект)
```
Больше клиентов
       ↓
Мойки хотят присоединиться (поток клиентов)
       ↓
Больше моек в сети
       ↓
Удобнее для клиентов (выбор)
       ↓
Ещё больше клиентов
       ↓
Конкурентам невозможно догнать!
```

#### 8. Data-Driven подход
```
Собираем данные:
- Где клиенты моют чаще
- В какое время
- Какие мойки популярны
- Откуда клиенты (районы)

Используем для:
- Привлечения партнёров в "горячих" районах
- Оптимизации цен
- Таргетированной рекламы
- Прогнозирования спроса
```

## 🔒 БЕЗОПАСНОСТЬ

### 1. Authentication Security

```
✅ Password Leak Protection (HaveIBeenPwned)
   - Проверка по базе 800+ млн взломанных паролей
   - Автоматический отказ при регистрации/смене

✅ Минимальная длина пароля: 8 символов
   - Рекомендуем 12+

✅ Rate Limiting
   - Регистрация: 10 попыток/час
   - Вход: 30 попыток/час
   - Сброс пароля: 10 попыток/час

✅ JWT токены
   - Access token: 1 час (короткий срок)
   - Refresh token: 30 дней
   - Хранение в httpOnly cookies (защита от XSS)

✅ HTTPS only
   - Let's Encrypt SSL сертификат
   - Все запросы шифруются
```

### 2. Database Security (RLS)

```sql
✅ Row Level Security (RLS)
   - Пользователи видят ТОЛЬКО свои данные
   - Мойщики видят только свою мойку
   - Партнёры видят только свою статистику

✅ SQL Injection защита
   - Prepared statements
   - Параметризованные запросы
   - ORM (Supabase клиент)

✅ Backup & Recovery
   - Автоматические бэкапы каждый день
   - Point-in-time recovery (можно откатиться)
   - Хранение 7 дней

✅ Encryption at Rest
   - Вся база зашифрована AES-256
   - Ключи в AWS KMS
```

### 3. QR Code Security

```
✅ Уникальный QR на каждую мойку
   - Формат: DRIVEPASS-USER123-WASH456-TS1234567890
   - UUID пользователя
   - Timestamp (метка времени)

✅ Время жизни: 10 минут
   - Защита от скриншотов
   - Нельзя "сохранить" QR и использовать позже

✅ One-time use
   - После сканирования QR недействителен
   - Нельзя помыть 2 машины по одному QR

✅ Проверка госномера
   - Мойщик видит: 30 A 777 AA
   - Должен совпадать с реальной машиной
   - Защита от передачи QR друзьям
```

### 4. Payment Security

```
✅ PCI DSS Compliance
   - НЕ храним данные карт
   - Используем Payme/Click (они PCI-сертифицированы)
   - Только transaction_id в базе

✅ 3D Secure
   - Двухфакторная аутентификация платежей
   - SMS код для подтверждения

✅ Fraud Detection
   - Подозрительные паттерны (50 регистраций с одного IP)
   - Blacklist краденых карт
   - Лимиты (макс 5 подписок с одной карты)
```

### 5. API Security

```
✅ CORS (Cross-Origin Resource Sharing)
   - Только наш домен может делать запросы
   - Защита от CSRF атак

✅ API Rate Limiting
   - 1000 запросов/час на пользователя
   - Защита от DDoS

✅ Input Validation
   - Zod схемы для всех форм
   - Санитизация (защита от XSS)
   - Проверка типов
```

### 6. Privacy & GDPR

```
✅ Прозрачность данных
   - Политика конфиденциальности
   - Пользователь видит какие данные хранятся

✅ Право на удаление
   - Кнопка "Удалить аккаунт"
   - Полное удаление из базы (GDPR)

✅ Минимизация данных
   - Храним только необходимое
   - Телефон, госномер, история моек
   - НЕ храним: геолокацию, фото, биометрию

✅ Анонимизация аналитики
   - Google Analytics без PII
   - Агрегированные метрики
```
