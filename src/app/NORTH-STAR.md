## Что мы строим

DrivePass+ — это не просто агрегатор автомоек.  
Это **подписка на спокойствие**. Водитель платит один раз в месяц и перестаёт думать о грязной машине навсегда.

Мы строим первую в Узбекистане модель **Car-Care-as-a-Subscription** — по образцу того, что Spotify сделал с музыкой и Netflix с кино.

## Принципы продукта

### 1. Zero Friction
Каждое касание пользователя с продуктом должно быть меньше 3 секунд.  
QR → Скан → Заезд. Без регистрации на мойке, без наличных, без очереди.

### 2. Trust by Design
Антифрод невидим для честного пользователя.  
Лимиты и кулдауны работают в фоне — пользователь их не замечает.

### 3. Partner First
Мойки — это наши клиенты тоже. Без партнёров нет продукта.  
Партнёрская панель должна быть настолько простой, чтобы её мог использовать человек без технического образования.

### 4. Local by Default
Язык — русский. Валюта — сум. Телефон — +998.  
Мы не копируем западные продукты. Мы создаём продукт для Узбекистана.

### 5. Pixel Perfect
Каждый экран — как будто его сделали в Apple.  
Белые карточки. Тени, которые едва заметны. Анимации, которые ощущаются как физика.

## Технический компас

- **Стек**: React 18 + TypeScript + Vite + Tailwind v4 + Supabase
- **Auth**: SMS OTP через Eskiz (Узбекистан), phone-first
- **Анти-фрод**: лимит 8 моек/мес (Standard), 12ч кулдаун
- **PWA**: работает как нативное iOS/Android приложение
- **Офлайн**: QR работает без интернета (кэш)

## Дизайн-философия

Вдохновение: **Apple Human Interface Guidelines** + **Linear.app** + **Raycast**

Цветовая система:
- `#2563EB` — Primary Blue (доверие, стабильность)
- `#007AFF` — iOS Blue (интерактивность)
- `#34C759` — iOS Green (успех, подтверждение)
- `#5856D6` — iOS Purple (партнёрская панель)
- `#FF9500` — iOS Orange (предупреждения, акценты)

Типографика: System UI → SF Pro на iOS, Roboto на Android  
Отступы: кратны 4px  
Радиусы: 12px (поля), 16px (карточки), 24px (модалки), 9999px (пилюли)
