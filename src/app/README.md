# 🚗 DrivePass+ 

**Unlimited clean. Unlimited drive.**

A premium car wash subscription app for $25/month with unlimited daily washes at partner locations.

---

## 🎉 What's New - ALL FEATURES IMPLEMENTED!

### ✨ Progressive Web App (PWA)
- 📲 Install on your phone like a native app
- 🚀 Works offline with cached data
- 🔔 Push notification support
- 📱 Perfect mobile experience on iOS & Android

### 🔐 Full Backend Integration
- ✅ User authentication (sign up/sign in)
- ✅ Cloud-synced wash history
- ✅ Real-time data with Supabase
- ✅ Secure API endpoints

### ⭐ Reviews & Ratings
- Write reviews for wash locations
- 5-star rating system
- Verified wash badges
- Sort by recent or helpful

### 🎁 Loyalty Rewards Program
- Earn 10 points per wash
- 4-tier membership (Bronze → Platinum)
- Redeem points for rewards
- Track your progress

## 📱 Quick Start

### For Users:

1. **Open in mobile browser** (Safari on iOS, Chrome on Android)
2. **Add to Home Screen**:
   - iOS: Tap Share → "Add to Home Screen"
   - Android: Tap Menu → "Add to Home Screen"
3. **Launch the app** from your home screen
4. **Sign up** with email and password
5. **Start washing!** Scan QR codes at partner locations

### For Developers:

```bash
# Backend is pre-configured with Supabase
# Service Worker registers automatically
# Just run the app - everything works!
```
