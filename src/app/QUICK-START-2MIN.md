## ⚡ ШАГ 1: НАСТРОЙ SUPABASE (30 сек)

### Отключи Email Confirmation для быстрого теста:

```
1. Открой: https://supabase.com/dashboard
2. Выбери свой проект
3. Перейди:
   
   Authentication (слева)
   └── Settings (вкладка)
       └── Auth Providers (раздел)
           └── Email (нажми Edit)
               └── [✓] Enable email confirmations
                   
                   ⚠️ ОТКЛЮЧИ этот чекбокс!
                   
4. Нажми: Save (внизу)
```

**✅ Готово!** Теперь регистрация сразу логинит пользователя.

## 🐛 Если что-то пошло не так:

### Ошибка: "email rate limit exceeded"

```
✅ Отключил Email Confirmation? (Шаг 1)
✅ Нажал Save в Supabase?
✅ Перезагрузил страницу?

Если всё равно не работает:
→ Используй другой email: test+1@test.com
→ Или подожди 1 час
```

### Ошибка: "Email not confirmed"

```
✅ Email Confirmation ОТКЛЮЧЕН? (должен быть)
✅ Если включен → отключи и попробуй снова
```

### Ошибка: "Too many attempts"

```
✅ Подожди 60 секунд
✅ Попробуй снова
```

### Приложение не открывается

```
✅ npm run dev запущен?
✅ Порт 5173 свободен?
✅ Supabase credentials в .env?
```
