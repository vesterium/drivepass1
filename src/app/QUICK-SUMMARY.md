```

```

## ТЕХНОЛОГИИ

```
FRONTEND:
├─ React 18.3.1 (UI)
├─ TypeScript 5.6.2 (типизация)
├─ Vite 6.0.11 (сборка)
├─ Tailwind CSS 4.0 (стили)
└─ Shadcn/UI (компоненты)

BACKEND:
├─ Supabase (BaaS платформа)
│  ├─ Auth (вход по телефону)
│  ├─ PostgreSQL (база данных)
│  ├─ Storage (файлы)
│  └─ RLS (безопасность)

PWA:
├─ Service Worker (офлайн)
├─ Web Manifest (установка)
└─ Push Notifications (уведомления)

ДОПОЛНИТЕЛЬНО:
├─ Zustand (state)
├─ React Hook Form (формы)
├─ QRCode.react (QR коды)
├─ Leaflet (карты)
└─ i18next (3 языка)
```
